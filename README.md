## About the Project
LearnWell is an explainable early-intervention platform designed to identify students who may be at academic or engagement risk at an early stage.
It uses attendance, assessment and assignment data to calculate a 0-100 risk score, explain the reasons behind it in plain language, and suggest suitable interventions to mentors. Mentors always make the final decision.

## Key Features
- Student academic risk identification (Green / Amber / Red bands)
- Explainable risk scores with the contributing factors listed
- Attendance and assessment analysis, including dynamic QR-based class attendance
- Personalized intervention suggestions with status tracking
- Faculty/Mentor dashboard
- Student dashboard
- Admin dashboard
- Mentor feedback, band overrides with audit log, and progress tracking
- Offline mentor AI assistant with data citations

## User Roles
1. Student
2. Faculty (Mentor)
3. Admin

## Technology Stack
| Layer | Technologies |
|---|---|
| **Frontend** | React 19, Vite, Tailwind CSS v4, React Router v7, Recharts, Lucide Icons, html5-qrcode, jsQR, qrcode.react |
| **Backend** | Python 3.13, FastAPI, Uvicorn, Pydantic v2, PyJWT, bcrypt, python-dotenv |

| **AI / Logic** | Rule-based explainable risk engine and offline mentor assistant (OpenAI/Gemini optional via API keys) |

## Data
All data in this project is **synthetic**. It is generated by `backend/app/seed_data.py` every time the backend starts. No real student information is used.

## Installation and Setup

**Prerequisites:** Python 3.10+ (developed on 3.13), Node.js 18+

### 1. Clone the repository
```
git clone https://github.com/YOUR_USERNAME/learnwell-shikshasetu.git
cd learnwell-shikshasetu
```

### 2. Environment file
```
cp .env.example .env
```
The defaults work offline. API keys are optional.

### 3. Backend Setup
```
cd backend
python -m venv venv
```
Activate the environment:
- Windows: `venv\Scripts\activate`
- macOS/Linux: `source venv/bin/activate`

Install dependencies and run:
```
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```
The backend runs at http://localhost:8000

### 4. Frontend Setup
In a new terminal:
```
cd frontend
npm install
npm run dev
```
The app runs at http://localhost:5173

### Quick start (both servers)
Run `run-dev.sh` (macOS/Linux) or `run-dev.bat` (Windows) from the project root.
